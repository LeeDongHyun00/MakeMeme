# 리스크 점검표

유행을 브랜드 콘텐츠에 쓰면 개인이 따라 할 때와 다른 책임이 생긴다. 선정 전(5단계)과 내보내기 전(7단계)에 유행마다 점검한다.

결과는 항목별로 **문제 없음 / 주의 / 사용 불가**로 표기한다. "사용 불가"가 하나라도 있으면 그 유행은 탈락시킨다.

## 1. 저작권·초상권

- **음원**: 개인 계정에서 쓸 수 있는 음원도 비즈니스 계정·광고에서는 쓸 수 없는 경우가 많다. 플랫폼의 상업용 음원 라이브러리에 있는지 확인이 필요하다고 표기한다. 확인 전에는 "주의".
- **영상·이미지 원본**: 방송·영화·타인 영상의 클립이나 캡처를 그대로 쓰는 안은 내지 않는다. 형식만 빌려 직접 촬영하는 안으로 바꾼다.
- **인물**: 연예인·일반인의 얼굴, 이름, 목소리, 유행어를 광고에 쓰면 초상권·퍼블리시티권 문제가 생길 수 있다. 특정 인물이 핵심인 밈은 인물 없이 형식만 살릴 수 있을 때만 쓴다.
- **캐릭터·상표**: 타사 캐릭터와 로고가 필수인 밈은 "사용 불가".

## 2. 부정적 맥락

`{유행명} 논란`, `{유행명} 유래`를 검색해 확인한다.

- 혐오·비하(성별, 지역, 세대, 장애, 인종, 외모)에서 유래했거나 그렇게 쓰이는가
- 정치적 진영과 묶여 있는가
- 사건·사고·재난·범죄, 고인과 관련 있는가
- 원본 당사자가 조롱당하는 구조인가, 당사자가 불쾌함을 표한 적 있는가
- 특정 커뮤니티 은어로 부정적 인식이 있는가
- 성적·폭력적 함의가 있는가

하나라도 해당하면 "사용 불가". 유래를 확인하지 못했으면 "주의"로 두고 사람이 확인하도록 적는다.

## 3. 브랜드 적합성

- 브랜드 톤과 충돌하지 않는가 (금융·의료·공공 등 신뢰가 중요한 업종은 더 엄격하게)
- 타깃이 이 유행을 아는가. 모르면 설명 없이는 통하지 않는다
- 제품·서비스를 깎아내리는 것처럼 읽히지 않는가
- 사용자가 정한 금지 사항에 걸리지 않는가

## 4. 광고·표시 규정

- 협찬·광고 콘텐츠는 경제적 이해관계를 명확히 표시해야 한다 (예: 영상·캡션 앞부분에 "광고" 표기)
- 효능·효과를 과장하거나 근거 없이 "최고", "유일", "1위"를 쓰지 않는다
- 식품·화장품·의료·금융 등 규제 업종은 업종별 광고 심의 기준을 따로 확인하도록 안내한다
- 경쟁사를 비방하거나 비교하지 않는다

법률 판단은 내리지 않는다. 확인이 필요한 지점을 짚고 담당자 확인을 권한다.

## 5. 유행 종료 위험

- 제작·승인에 걸리는 시간 안에 유행이 끝나지 않는가
- 이미 여러 브랜드가 써서 식상하지 않은가
- 하락 신호("이제 그만", "유행 지남")가 보이면 탈락

## 표기 예시

```
저작권·초상권: 주의 — 음원 상업적 사용 가능 여부 확인 필요. 원본 클립은 쓰지 않고 직접 촬영
부정적 맥락: 문제 없음 — 유래 확인 (링크)
브랜드 적합성: 문제 없음
광고 표시: 주의 — 자사 계정 게시물이면 표시 불필요, 인플루언서 협업 시 표시 필요
유행 종료 위험: 주의 — 정점 단계, 5일 내 게시 권장
```

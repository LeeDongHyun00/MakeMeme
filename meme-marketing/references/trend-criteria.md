# 유행 판정 기준

후보 하나하나를 아래 5개 지표로 채점해 100점 만점으로 판정한다.

## 점수표

### 1. 확산 속도 (30점)

짧은 시간에 얼마나 빨리 퍼졌는가. 누적 수치가 아니라 **시간 대비 증가**를 본다.

| 점수 | 기준 |
|---|---|
| 25~30 | 게시 24시간 내 조회수 100만 회 이상, 또는 YouTube 인기 급상승 상위권, 또는 채널 평균의 10배 이상 |
| 15~24 | 24시간 내 10만 회 이상, 또는 채널 평균의 3배 이상, 또는 플랫폼 인기·추천 탭 진입 |
| 5~14 | 며칠에 걸쳐 꾸준히 증가, 급등은 확인되지 않음 |
| 0~4 | 증가세 근거 없음 |

시간당 조회수 = 조회수 ÷ 게시 후 경과 시간. 같은 조회수라도 게시 6시간 차 영상이 6일 차 영상보다 강한 신호다.

### 2. 참여도 (20점)

본 사람이 얼마나 반응했는가.

| 점수 | 기준 |
|---|---|
| 16~20 | 좋아요율(좋아요÷조회수) 6% 이상, 또는 공유·저장·댓글이 이례적으로 많다는 보도·지표 |
| 10~15 | 좋아요율 4% 이상, 댓글에서 따라 하기·인용이 활발 |
| 4~9 | 좋아요율 2~4%, 평범한 반응 |
| 0~3 | 반응 근거 없음 |

숏폼은 일반 영상보다 좋아요율이 낮게 나오는 편이므로, 같은 플랫폼·형식끼리 비교한다.

### 3. 재생산 (20점)

밈과 단순 인기 영상을 가르는 지표다. 사람들이 **따라 만들고 있는가**.

| 점수 | 기준 |
|---|---|
| 16~20 | 패러디·리믹스·챌린지가 다수이고 연예인·브랜드·공공기관 계정까지 차용 |
| 10~15 | 일반 사용자의 변형이 여럿 확인되고 사운드·템플릿으로 재사용됨 |
| 4~9 | 댓글·게시글에서 문구만 인용되는 수준 |
| 0~3 | 원본만 있고 변형 없음 |

재생산 점수가 4점 미만이면 총점과 관계없이 밈이 아니라 "화제 영상"으로 분류하고 콘텐츠 결합 대상에서 뺀다. 따라 할 형식이 없기 때문이다.

### 4. 교차 확산 (15점)

| 점수 | 기준 |
|---|---|
| 12~15 | 3개 이상 플랫폼에서 확인되고 뉴스·방송에서도 언급 |
| 7~11 | 2개 플랫폼에서 확인 |
| 0~6 | 한 플랫폼·한 커뮤니티 안에서만 유통 |

플랫폼: YouTube, Instagram, TikTok, X, 온라인 커뮤니티, 메신저·오픈채팅 언급, 뉴스.

### 5. 최신성 (15점)

| 점수 | 기준 |
|---|---|
| 12~15 | 정점이 최근 3일 이내이거나 아직 상승 중, 검색량 급등 확인 |
| 7~11 | 정점이 최근 7일 이내 |
| 3~6 | 정점이 8~14일 전 |
| 0~2 | 그보다 오래됨 |

검색량은 Google Trends, 네이버 데이터랩으로 확인한다.

## 판정

| 총점 | 판정 | 처리 |
|---|---|---|
| 70 이상 | 유행 | 콘텐츠 결합 대상 |
| 50~69 | 떠오르는 중 | 요약표에 표시, 적합한 유행이 부족할 때 대안으로 사용 |
| 50 미만 | 제외 | 탈락 목록에만 기록 |

## 생애 단계

| 단계 | 신호 | 처리 |
|---|---|---|
| 초기 | 원본이 며칠 내 게시, 변형이 막 늘어나는 중, 브랜드 차용 거의 없음 | 가장 좋은 시점. 선점 효과 큼 |
| 정점 | 변형이 넘치고 브랜드·연예인이 차용, 뉴스에서 다룸 | 사용 가능. 3~5일 내 게시 권장, 차별화 필요 |
| 하락 | 변형 게시가 줄어듦, "이제 지겹다" 반응, 지상파·관공서가 뒤늦게 사용, 검색량 하락 | 제외 |

예상 유효 기간은 단계와 형식으로 추정한다. 사운드·챌린지형은 대체로 1~3주, 문구·말투형은 수 주~수개월 간다. 추정임을 밝힌다.

## 신뢰도

수치를 직접 확인하지 못하는 경우가 많으므로 판정마다 신뢰도를 붙인다.

| 신뢰도 | 조건 |
|---|---|
| 높음 | 조회수·좋아요 등 수치를 원본이나 API로 직접 확인, 독립 출처 3개 이상 |
| 중간 | 수치는 일부만 확인, 독립 출처 2개 이상이 유행이라고 서술 |
| 낮음 | 수치 미확인, 출처가 서로 인용 관계이거나 2개뿐 |

규칙:

- **독립 출처가 2개 미만이면 유행으로 판정하지 않는다.** 서로 베낀 기사, 같은 글의 재게시는 하나로 센다.
- 수치를 확인하지 못한 지표는 정황 근거(기사 서술, 변형 게시물 수 등)로 구간의 **아래쪽** 점수를 준다.
- 확인하지 못한 수치를 추정해서 적지 않는다. "확인 불가"로 쓴다.
- 신뢰도 "낮음"인 유행을 선정할 때는 결과에 그 사실을 분명히 적는다.

## 채점 기록 형식

```
유행명: OOO
확산 속도 22/30 — 게시 18시간 만에 조회수 85만 (원본 링크, 확인일)
참여도 12/20 — 좋아요율 4.8%
재생산 16/20 — 변형 릴스 다수, 브랜드 계정 2곳 차용 (링크)
교차 확산 11/15 — Instagram, X에서 확인
최신성 13/15 — 원본 3일 전 게시, 상승 중
총점 74 → 유행 / 단계: 초기 / 신뢰도: 중간
```

# 산출물 양식

## 전체 구성

```
조사 기준: YYYY-MM-DD
가정한 조건: (있을 때만) 타깃 OO, 톤 OO, 채널 OO

## 유행 요약표
## 선정 유행 1 / 2 / 3
## 탈락 유행
## 확인하지 못한 것
```

## 유행 요약표

| 유행명 | 점수 | 판정 | 단계 | 신뢰도 | 예상 유효 기간 | 주요 출처 |
|---|---|---|---|---|---|---|
| OOO | 74 | 유행 | 초기 | 중간 | 약 2주 | 링크 |

채점한 후보 전체를 점수순으로 싣는다. 선정한 3개에는 표시를 한다.

## 선정 유행 (유행마다 반복)

### 유행 내용

- **원본**: 누가, 어디서, 언제 (링크)
- **형식**: 고정 부분 / 바꿔 끼우는 부분
- **왜 따라 하는가**:
- **주 사용층**:
- **단계·유효 기간**: 정점, O월 O일까지 게시 권장
- **판정 근거**: 지표별 점수와 근거 (채점 기록 형식)

### 연결 설명

유행의 어느 부분에 주제를 어떻게 끼웠는지 한 줄.

> 예: "OO 하는 사람 vs 안 하는 사람" 대비 구조의 '하는 사람' 자리에 제품 사용 장면을 넣음.

### 숏폼 영상 기획안

| 항목 | 내용 |
|---|---|
| 채널 | YouTube Shorts / Instagram Reels / TikTok |
| 길이 | 15~30초 권장 (유행 원본 길이에 맞춘다) |
| 사운드 | 유행 음원명 또는 "원본 음원 사용" — 상업적 사용 가능 여부 확인 필요 표기 |
| 촬영 난이도 | 낮음(스마트폰 1인) / 중간 / 높음 |

장면 구성:

| 시간 | 화면 | 대사·내레이션 | 자막 |
|---|---|---|---|
| 0~3초 (훅) | | | |
| 3~10초 | | | |
| 10~20초 | | | |
| 마지막 | | | |

- **첫 3초 훅**: 유행의 고정 부분으로 시작해 "그 밈이다"를 바로 알아보게 한다.
- **행동 유도 문구**: 마지막 장면이나 캡션에 하나만.
- **변형 아이디어**: 같은 틀로 만들 수 있는 후속편 1~2개.

### SNS 게시물 문구

채널별로 캡션 2~3안. 안마다 접근 방식을 달리한다.

```
[Instagram]
A안 (공감형):
B안 (반전형):
C안 (정보형):
해시태그: #유행태그 #유행태그 #브랜드태그 #주제태그 (5~10개)

[YouTube Shorts]
제목 (40자 이내):
설명:

권장 게시 시점: O월 O일 이전, 타깃 활동 시간대(예: 평일 저녁 7~10시)
```

- Instagram 캡션은 첫 줄에서 승부한다 (더보기 전에 보이는 부분).
- Shorts 제목에는 유행 키워드를 넣어 검색에 걸리게 한다.
- 채널을 지정받았으면 그 채널만 쓴다.

### 리스크 점검

`brand-safety.md` 항목별 결과를 표기한다.

```
저작권·초상권: 주의 — 원본 음원 상업적 사용 가능 여부 확인 필요
부정적 맥락: 문제 없음 (유래 확인, 링크)
광고 표시: 해당 — 협찬·광고 시 표시 필요
유행 종료 위험: 낮음
```

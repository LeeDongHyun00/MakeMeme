# 수집 출처와 검색어 패턴 (한국 시장)

유행 후보는 한 곳에서만 찾지 않는다. 아래 출처를 고르게 살피고, 서로 다른 출처에서 같은 유행이 반복해 나오는지를 본다.

## 검색 원칙

- 검색어에 **연·월**을 넣는다 (예: "2026년 11월 밈"). "요즘", "최근"만 쓰면 몇 달 전 글이 섞인다.
- 결과의 **게시일**을 반드시 확인한다. 7일보다 오래된 자료는 유행의 배경 설명으로만 쓰고 근거로는 쓰지 않는다.
- 유행 이름을 알게 되면 그 이름으로 **다시 검색**해 원본, 변형 사례, 확산 시점을 확인한다.
- 한 번의 검색으로 끝내지 않는다. 종합 검색 → 플랫폼별 검색 → 유행명 검증 검색 순으로 최소 6~10회 검색한다.

## 이번 달 자료가 안 나올 때

월초이거나 검색 엔진 반영이 늦으면 `{연월}` 검색에 지난달·몇 달 전 정리 글만 나온다. 이때는 다음 순서로 대응한다.

1. 밈·트렌드를 정기적으로 정리하는 매체의 **가장 최근 글**을 찾는다. 예: 고구마팜(gogumafarm.kr), 위픽레터(letter.wepick.kr), 캐릿(careet.net), 오픈애즈(openads.co.kr), 아이보스(i-boss.co.kr). `{매체명} 밈 최신`, `{매체명} 이번 주 트렌드`로 검색하고 글의 게시일을 확인한다.
2. `이번 주`, `어제`, `실시간` 같은 표현과 플랫폼명을 조합해 다시 검색한다.
3. 그래도 7일 이내 자료가 없으면, 가장 최근 정리 글의 밈을 **후보**로만 삼고 유행명 검증 검색으로 지금도 변형이 올라오는지 확인한다. 확인되지 않으면 최신성 점수를 낮게 주고 하락 단계 여부를 따진다.
4. 끝내 최신 자료를 얻지 못했으면 결과의 "확인하지 못한 것"에 "최근 7일 자료 미확보, 가장 최근 근거는 O월 O일 자"라고 적는다. 오래된 밈을 현재 유행인 것처럼 내놓지 않는다.

## 검색어 패턴

`{연월}`은 오늘 기준 연·월, `{주제}`는 마케팅 주제나 업종으로 바꾼다.

### 종합

- `{연월} 요즘 유행하는 밈`
- `{연월} 밈 정리` / `이번 주 밈 모음`
- `{연월} 유행어 신조어`
- `요즘 SNS 유행 챌린지 {연월}`

### 플랫폼별

- YouTube: `유튜브 인기 급상승 {연월}`, `쇼츠 유행 {연월}`, `쇼츠 챌린지 요즘`
- Instagram: `릴스 유행 {연월}`, `릴스 인기 음원 {연월}`, `인스타 릴스 트렌드 이번 주`
- TikTok: `틱톡 유행 챌린지 {연월}`, `틱톡 인기 사운드 {연월}`
- X: `트위터 실시간 트렌드 밈`, `X 유행 짤 {연월}`
- 커뮤니티: `커뮤니티 유행 짤 {연월}`, `요즘 유행하는 말투`

### 주제·업종 연계

- `{주제} 릴스 유행`
- `{주제} 밈 마케팅 사례 {연월}`
- `브랜드 계정 밈 패러디 {연월}`

### 유행명 검증 (후보를 찾은 뒤)

- `{유행명} 원본`
- `{유행명} 뜻 유래`
- `{유행명} 패러디` / `{유행명} 챌린지`
- `{유행명} 논란` ← 리스크 점검용, 빠뜨리지 않는다

## 출처별 특징

| 출처 | 얻을 수 있는 것 | 주의 |
|---|---|---|
| YouTube 인기 급상승 (한국) | 조회수, 게시 시각, 좋아요 수 등 수치 | 뮤직비디오·방송 클립이 많아 밈이 아닌 것이 섞임. 재생산 여부를 따로 확인 |
| Instagram 릴스 | 인기 음원 사용 게시물 수, 변형 사례 | 공식 급상승 목록·API 없음. 트렌드 정리 글과 실제 게시물로 확인 |
| TikTok | 사운드·해시태그별 게시물 수, 챌린지 | 해외 유행이 섞임. 국내 사용 여부 확인 |
| X | 실시간 트렌드, 짤·문구형 밈의 초기 확산 | 수명이 짧고 특정 팬덤 한정인 경우가 많음 |
| 온라인 커뮤니티 | 유행의 발원지, 초기 신호 | 커뮤니티 성향에 따른 부정적 맥락 가능. 유래를 반드시 확인 |
| Google Trends / 네이버 데이터랩 | 검색량 급등 시점 | 유행 이름을 알아야 조회 가능 |
| 트렌드 뉴스레터·매체, 마케팅 블로그 | 정리된 유행 목록, 브랜드 차용 사례 | 발행 시점에 이미 정점일 수 있음. 게시일 확인 |
| 나무위키 등 위키 | 유래와 변형 정리 | 최신성 근거로는 약함. 배경 확인용 |

## 해외 유행 처리

해외에서 시작된 유행은 아래 중 하나가 확인될 때만 후보에 넣는다.

- 국내 계정이 만든 변형이 여럿 있다
- 국내 매체·커뮤니티에서 유행으로 다뤘다
- 한국어 자막·번안 버전이 퍼지고 있다

## YouTube API 스크립트 (선택)

코드 실행이 가능하고 `YOUTUBE_API_KEY` 환경 변수가 있으면 실행한다.

```bash
python scripts/youtube_trending.py --region KR --max 50 --format table
```

출력의 `views_per_hour`(시간당 조회수), `like_rate`(좋아요율)를 확산 속도·참여도 점수의 근거로 쓴다. 인기 급상승 목록에는 밈이 아닌 영상도 많으므로, 목록에서 제목·형식이 반복되는 것(같은 사운드, 같은 챌린지)을 찾아 후보로 삼는다.

Instagram과 TikTok은 공식 급상승 API가 없어 스크립트가 다루지 않는다.
